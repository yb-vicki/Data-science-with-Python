# Data Science with Python

A structured laboratory of data science foundations, data wrangling pipelines, and statistical computing exercises. This repository is designed to reinforce the core concepts of data cleaning, exploratory data analysis (EDA), visualization, and algorithmic problem-solving using Python.

This is a foundational coursework repository rather than an end-to-end production application. The emphasis is on learning reproducible data workflows, interpreting results, and building practical fluency with essential data-science tools.

## Project index

### 1. Coding for answers
Focused on algorithmic and analytical problem-solving using Python. These exercises reinforce logical reasoning, data manipulation, and solution design across small but representative data tasks.

- `jean-pockets-project`: problem-solving using structured data and conditional logic
- `largest-islands-project`: pattern and numerical analysis exercises
- `naming-colors-project`: classification and text-driven data tasks
- `people-on-banknotes-project`: dataset interpretation and feature-based reasoning

### 2. Data Cleaning
Covers the fundamentals of preparing raw data for analysis: missing-value handling, type conversions, normalization, filtering, and transformation workflows.

- `emoji-sentiment-project`: text and categorical cleaning for sentiment-style analysis
- `solar-eclipses-project`: real-world data cleanup and inspection
- `top-songs-project`: structured dataset cleaning and consistency checks
- `typing-speeds-project`: data standardization and exploratory processing
- `volcanic-eruptions-project`: cleaning and transforming observational data
- `whale-heart-rates-project`: time-series and measurement data preparation

### 3. Data Visualization
Introduces the practice of turning cleaned data into interpretable visual evidence. These tasks emphasize chart design, trend detection, and communicating findings clearly.

- `granola-healthy-project`: exploratory visualization and business-style reporting

The work here is intentionally instructional and research-oriented. It emphasizes conceptual clarity, reproducibility, and foundational practice rather than production deployment or end-to-end ML system design.
